# FastLAN – LAN File Transfer Application

FastLAN is a Java-based desktop application that allows users to transfer files between computers connected to the same Local Area Network (LAN).

## Features

- Easy-to-use graphical user interface.
- Send and receive files between computers.
- Transfer multiple files.
- Real-time transfer progress.
- File size and transfer speed display.
- Select destination folder for received files.
- Start and stop file receiving.
- Error handling and transfer status messages.

## Technologies Used

- Java
- Java Swing (GUI)
- Java Socket Programming
- Multithreading
- File Handling
- Object-Oriented Programming

## Project Structure

- `MainWindow.java` – Main application interface.
- `FileTransferClient.java` – Handles file sending.
- `FileTransferServer.java` – Handles file receiving.
- `TransferListener.java` – Handles transfer events.
- `fastlan-icon.png` – Application logo.

## How It Works

Both computers must be connected to the same Local Area Network. One computer sends files while the other receives them using socket communication.
